<design_decisions>
Settled here so the executor does not guess. These honor the user request verbatim and the
project constraints (stdlib-only tests, no third-party deps, do NOT rewrite root algebra.go
or internal/ packages — only ADD).

**D1 — Universal AST node set (pkg/ast).** Sealed interface `Expr` (unexported `isExpr()`
marker) + struct nodes with exported read-only fields, constructors `NewXxx`, no setters
(immutable by convention, per project coding style): `Const{Value int}`, `Symbol{Name string}`
(static compile-time parameters, substituted by the consumer at IR-lowering time), `Var{Name,
Family string}` (Family "" allowed — f2 bit variables carry no family), and binary ops
`Xor`, `And` (bit-level: f2 addition/multiplication), `Add`, `Sub`, `Mul`, `Div`, `Mod`
(integer: Div is truncating, Mod is Go `%` — matching internal/subgroupchain Eval semantics
exactly), plus `Tuple{Elem []Expr}` (ordered; represents f2 bit vectors MSB-first AND
subgroupchain hierarchical coordinate tuples — one structural node serves both). Supporting
API: `Eval(e Expr, assignment map[string]int) (int, error)`, `Children(e Expr) []Expr`,
`Walk(e Expr, fn func(Expr) bool)` (pre-order; fn false stops that subtree), `String()` on
every node (infix, parenthesized) and `Dump(e Expr) string` (multi-line prefix form for deep
trees). Eval errors: missing assignment, Div/Mod by zero, Eval of Tuple (structural node has
no scalar value).

**D2 — Composition with the root interface.** pkg/layout does BOTH, sharing one set of
per-algebra stage helpers: (a) root-registry adapters `algebraF2` / `algebraSubgroupChain`
implementing `layoutalgebra.Algebra`, self-registered in `init()` via `layoutalgebra.Register`
— native artifacts travel opaquely in `Mapping.Value` / `Offset.Value` exactly as doc.go
envisions; (b) the user-facing abstract factory `Engine`/`Session` whose stage methods return
`*layout.Mapping{Algebra Kind; Access ast.Expr; Offset ast.Expr}` directly. The Engine holds
its backend directly (no registry indirection); the adapters exist for root-interface
consumers. Nothing in the root package is modified.

**D3 — Lowering passes.** Live in pkg/layout/lower.go. f2: an offset Vector (MSB-first) maps
to the weighted sum Add/Mul chain Σ lower(bit_i) · Const(2^(n-1-i)); a bare f2 expr maps
NodeVariable→Var, NodeConst→Const(0|1), NodeSymbol→Symbol, NodeBinary op f2.Xor→Xor /
op f2.And→And (f2.Add==f2.Xor, f2.Mul==f2.And). subgroupchain: Variable→Var{Name,Family},
Const→Const, Symbol→Symbol, Binary op Add/Sub/Mul/Div/Mod→matching node, Coordinate
"(source % radix) / stride"→`Div(Mod(lower(source), Const(radix)), Const(stride))`, Stride
dot-product→left-folded `Add` of `Mul(lower(coord_i), Const(stride_i))` (zero operands →
Const(0), the rank-1 empty Stride). Public dispatch on the opaque artifacts:
`LowerAccess(layoutalgebra.Mapping) (ast.Expr, error)` and
`LowerOffset(layoutalgebra.Offset) (ast.Expr, error)`, switching on the `Algebra` name field
and erroring on unknown names/value types. Correctness bar: AST evaluation ≡ native numeric
evaluation over the full assignment space (tests below).

**D4 — f2 adapter conventions.** Problem → native translation: every tile extent and
concurrency bound must be a power of two (Supported rejects otherwise, and rejects
Σlog2(bounds) ≠ Σlog2(extents)); bit j of variable v is named `v.Name + strconv.Itoa(j)`
(j = significance, 0 = LSB); the hw Vector is assembled MSB-first following
Problem.Concurrency order, each variable's bits high-index-first; `Bank.VariablePrefix` for
SMEM = the lane variable's Name (NameBelong is a HasPrefix match, verified in
swizzle_map.go:45). f2.StrideMap takes dtypeSize as the EXPONENT (0/1/2) — convert
Problem.Tile.DTypeSize bytes 1/2/4 → 0/1/2. dataCoord for Access/Smem = the hw vector itself
(identity permutation — the "normal" tiling). Internal artifact struct `f2Artifacts{hw
f2.Vector; coord f2.Vector; axes []f2.GmemAxis; laneBits, dtypeExp, shiftBits int}`:
Access sets coord = MapAccess result, shiftBits = dtypeExp; GmemOptimize calls
f2.GmemOptimizeWith(hw, axes, laneBits, dtypeExp, seg) and sets coord =
result.Plan.Matrix.Apply(hw) (CoeffMat.Apply, verified coeff_mat.go:192), shiftBits =
dtypeExp; SmemOptimize calls f2.SmemOptimize(hw, hw, dtypeExp, Bank{Skip, Range, prefix}) and
sets coord = result.Offset (already byte-space and swizzled), shiftBits = 0. Adapter
StrideMap = f2.StrideMap(make([]int, coord.Size()), coord, shiftBits) (dummy shape slice of
matching length is the established pipeline.go idiom). Saturation is already absorbed inside
f2.SmemOptimize (returns Swizzled=false result, no error).

**D5 — subgroupchain adapter conventions.** BoV = Problem.Concurrency in the GIVEN order
(order is semantic: major→minor; document "put the lane variable last"); env =
subgroupchain.NewEnv(); bov built via env.Factory.Variable(family, name, bound); tile =
NewConstHTuple(Problem.Tile.Shape) (flat — nested shapes stay a native-only feature);
Mapping.Value = `sgcArtifacts{env *Env; bov []*Variable; layout *Layout; lane int}` with
layout = &Layout{Coordinate: Access(env, bov, tile), Shape: tile}. Supported checks
Π(bounds) == Π(extents) (the native soundness precondition) — subgroupchain accepts
non-power-of-2. StrideMap = subgroupchain.StrideMap(env, layout, DTypeSize) — NOTE: native
takes dtype size in BYTES here (validates 1/2/4), no exponent conversion. GMem/Smem mutate
the layout in place, so the adapters must deep-copy first:
`Layout{Coordinate: ht.Clone(), Shape: sameShape}` (HTuple.Clone exists, htuple.go:375;
ConstHTuple is constants-only, share it) — immutable-pattern compliance. Configs:
GMemCoalesce{ByteSize: opts.lineBytes, VariableFamily: lane.Family}; SmemCoalesce{
VariableFamily: lane.Family, BankBytes: opts.bankBytes}. Errors propagate unchanged
(conservative contract).

**D6 — Facade option surface.** `New(kind Kind, opts ...Option)`: defaults LineBytes=128,
BankBytes=128, BankWindow={Skip:2, Range:5} (CUDA); options WithLineBytes(n) (power of 2,
≥32; feeds f2 Segment{Sector:5, Line:log2(n)} and sgc GMemCoalesce.ByteSize), WithBankBytes(n),
WithBankWindow(skip, range). NewSession runs Problem.Validate() then backend Supported —
reject loudly at the boundary (input validation rule). Each Session stage method is
independent: it rebuilds the native pipeline from the Problem and lowers fresh ASTs.

**D7 — What each stage returns.** Mapping.Access = the tile-coordinate mapping AST (Tuple:
f2 = one child per bit, MSB-first; sgc = hierarchy mirroring the tile shape). Mapping.Offset
= the final byte-offset AST the compiler translates to IR. For the SMEM stage Mapping.Access
is the PRE-swizzle coordinate mapping and Mapping.Offset the POST-swizzle offset (the swizzle
lives in byte space; documented on the type).
</design_decisions>

    func WithBankBytes(n int) Option
    func WithBankWindow(skip, range int) Option
    type Engine struct{ ... }

    func (e *Engine) Kind() Kind

    eng, _ := layout.New(layout.F2)            // or layout.SubgroupChain

    base, _ := sess.Access()        // base.Access (Tuple), base.Offset

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-q1-01 | Tampering | NewSession / stage entry | mitigate | Problem.Validate + Supported before any native call; option validation (power-of-2 line bytes, positive windows) |
| T-q2-02 | Tampering | LowerAccess/LowerOffset | mitigate | dispatch keyed on Algebra name; type-switch with default error — never panic on unknown Value |
| T-q3-03 | Denial of Service | ast.Eval on user-built trees | accept | pure library, no untrusted input in scope; deep recursion bounded by producer-built trees |
| T-q4-04 | Repudiation/Information disclosure | error messages | accept | errors carry variable names and op kinds only — no secrets exist in this library |

Pure in-process symbolic library: no network, exec, file, or secret surface. No package
installs (stdlib only), so the package-legitimacy gate does not apply.
